# My Commit Project

## Жоба туралы

Бұл жоба HTML, CSS және JavaScript технологияларын пайдаланып сайт құруға арналған. Жобаның мақсаты — веб-беттің құрылымын жасау, дизайнын баптау және JavaScript арқылы функционалдылық қосу. Сонымен қатар, Git көмегімен жобаның нұсқаларын басқару және тармақтармен жұмыс істеу дағдылары үйретіледі.

## Қолданылған технологиялар

- HTML5 — веб-беттің құрылымын құру.
- CSS3 — сайттың дизайнын жасау.
- JavaScript — сайтқа интерактивтілік қосу.
- Git — өзгерістерді бақылау және нұсқаларды басқару.
- GitHub — жобаны қашықтағы репозиторийде сақтау.
- GitHub Actions — CI/CD процестерін автоматтандыру.

## Әзірлеу ортасын баптау

1. Git және Visual Studio Code бағдарламаларын орнату.
2. GitHub репозиторийін компьютерге клондау немесе жобаның жергілікті бумасын ашу.
3. Жоба бумасын Visual Studio Code арқылы ашу.
4. `index.html` файлын браузерде іске қосу.

## Жоба құрылымы

- `index.html` — сайттың негізгі HTML файлы.
- `assets/css/style.css` — сайттың стильдері.
- `assets/js/main.js` — JavaScript коды.
- `CHANGELOG.md` — жоба нұсқаларындағы өзгерістер журналы.
- `README.md` — жоба туралы ақпарат.
- `.github/workflows/ci-cd.yml` — CI/CD автоматтандыру файлы.

## Git тармақтарымен жұмыс

- `main` — дайын және тексерілген нұсқаларды сақтау.
- `develop` — әзірлеу жұмыстарын біріктіру.
- `feature/task-3` — жаңа функцияларды әзірлеу.

## CI/CD процестерін автоматтандыру

Жобада GitHub Actions көмегімен CI/CD Pipeline іске асырылған.

CI (Continuous Integration) — кодтағы өзгерістерді автоматты түрде тексеру процесі.

CD (Continuous Delivery/Deployment) — тексерілген жобаны орналастыру процесін автоматтандыру.

Workflow автоматты түрде келесі жағдайларда іске қосылады:

- `main` тармағына жаңа өзгерістер жіберілгенде (Push).
- `main` тармағына Pull Request жасалғанда.

### Pipeline кезеңдері

1. **Build** — жобаны жинау кезеңі.
2. **Test** — тестілеу кезеңі.
3. **Deploy** — жобаны орналастыру кезеңі.

Deploy кезеңі Build кезеңі сәтті аяқталғаннан кейін орындалады.

CI/CD нәтижесін GitHub репозиторийіндегі Actions бөлімінен көруге болады.

Ескерту: осы зертханалық жұмыста Deploy кезеңі шартты түрде орындалады.

## Командалық жұмыс

Жоба командалық жұмыс принциптері бойынша орындалады.

- Team Leader (диктатор) — негізгі репозиторийді басқарады, өзгерістерді тексереді және Pull Request қабылдайды.
- Екінші қатысушы — Fork арқылы жоба көшірмесімен жұмыс істейді, өзгерістер енгізеді және Pull Request жібереді.

### Pull Request-пен жұмыс істеу

1. Негізгі репозиторийді Fork жасау.
2. Жеке тармақ құру.
3. Қажетті өзгерістер енгізу.
4. Өзгерістерді Commit және Push арқылы сақтау.
5. Негізгі репозиторийге Pull Request жіберу.
6. Өзгерістерді тексеріп, Merge жасау.

## Қосымша нұсқаулық

Git тармақтарымен жұмыс істеу және жобаны басқару бойынша тапсырма нұсқаулығын қараңыз.

CI/CD нәтижелерін тексеру үшін GitHub → Actions бөліміне өтіңіз.
